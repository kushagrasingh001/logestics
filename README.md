# QuickRoute Logistics — UI Prototype

A responsive HTML/CSS/JavaScript prototype for a B2B bulk logistics website.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code + Live Server.
3. Use the top navigation or sidebar to open pages.

## Demo pages
- Public homepage, services, about, contact
- Freight quote calculator
- Customer login/signup (visual demo only)
- Customer dashboard
- Shipment booking
- Shipment tracking
- Shipment history
- Agent dashboard
- Pickup / Hub In / Hub Out scan page
- Admin dashboard
- Shipment management
- Agent management
- Hub management
- Rate card management
- Reports

## Important limitations
This is a front-end prototype, not a production logistics system. Sample shipment data is stored in browser localStorage. Authentication, authorization, server-side validation, secure database storage, actual rate cards, route distance, tax, vehicle availability, email/SMS, payments, and real tracking integrations are not implemented. The sample freight calculation is illustrative only and must not be used as a real commercial quote. Before a business launch, connect a secure backend/database, implement server-side permissions and status rules, confirm the client's actual pricing logic, and conduct security and operational testing.
